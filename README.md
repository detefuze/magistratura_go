# helloapi

Минимальный HTTP-сервис на Go, созданный в рамках практического занятия №1 по дисциплине
«Технологии индустриального программирования».

Сервис написан на стандартной библиотеке `net/http` и демонстрирует базовые приёмы работы с Go:
инициализацию модуля, организацию структуры проекта, обработку HTTP-запросов, формирование
JSON-ответов и подключение внешней зависимости.

## Возможности

| Маршрут  | Метод | Ответ                                                      |
|----------|-------|------------------------------------------------------------|
| `/hello` | GET   | Текстовый ответ `Hello, world!` (тип `text/plain`)          |
| `/user`  | GET   | JSON-объект `{"id": "<UUID>", "name": "Gopher"}`            |
| `/health`| GET   | JSON-объект `{"status": "ok", "time": "<RFC3339>"}`         |

Значение `id` в `/user` генерируется как настоящий UUID v4 с помощью библиотеки
[`github.com/google/uuid`](https://github.com/google/uuid). Поле `time` в `/health` содержит
текущее время сервера в формате RFC3339.

## Требования

- Go 1.27 или новее (см. директиву `go` в `go.mod`).
- Git (для клонирования репозитория).
- Доступ в интернет при первой сборке — для загрузки внешней зависимости.

## Структура проекта

```
helloapi/
  cmd/
    server/
      main.go     # точка входа и обработчики HTTP-запросов
  go.mod          # описание модуля и зависимостей
  go.sum          # контрольные суммы (хеши) зависимостей
  README.md       # этот файл
```

Каталог `cmd` содержит точки входа исполняемых программ; сама логика размещается в `cmd/server`.

## Запуск

Запуск из корня проекта:

```bash
go run ./cmd/server
```

После запуска в логе появится сообщение `Starting on :8080 ...`, а сервер начнёт прослушивать
порт `8080`.

## Сборка

Сборка исполняемого файла:

```bash
go build -o helloapi.exe ./cmd/server
```

Запуск собранного файла:

```bash
# Windows
.\helloapi.exe

# Linux/macOS
./helloapi
```

## Примеры запросов

```bash
curl http://localhost:8080/hello
# Hello, world!

curl http://localhost:8080/user
# {"id":"3f1c1c5c-9a1b-4a6a-8a26-7b3f2f7d8b0b","name":"Gopher"}

curl http://localhost:8080/health
# {"status":"ok","time":"2026-10-09T10:15:00Z"}
```

## Конфигурация

Порт, который прослушивает сервер, задаётся переменной окружения `APP_PORT`. Если переменная
не задана, используется порт `8080`.

Windows (PowerShell):

```powershell
$env:APP_PORT="8081"
go run ./cmd/server
```

Linux/macOS:

```bash
APP_PORT=8081 go run ./cmd/server
```

При заданном значении сервер запустится на выбранном порту, например `:8081`.
